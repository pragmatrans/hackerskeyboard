# Що змінилось

Форк Hacker's Keyboard з українським словником і ручною корекцією одруківок.
Кожна версія — окремий реліз з APK: [Releases](https://github.com/pragmatrans/hackerskeyboard/releases).
Усі збірки підписані одним ключем, тому ставляться поверх попередніх.

Позначки: **[uk16]** — поточна.

---

## v1.41.1-uk16 — підказки команд з оглядкою на контекст

- Підказки термінальних команд тепер враховують **попереднє слово**: після `git` угорі стоять
  git-команди, після `docker` — docker, так само `apt`/`pkg`, `systemctl`, `ssh`/`curl`/`nmap`/`rsync`,
  `python`/`pip`/`npm`.
- Контекст читається одним запитом на 64 символи перед курсором; нічого не зберігається між
  натисканнями, у полях паролів читання не виконується взагалі, у WebView-полях просто не спрацьовує.

## v1.41.1-uk15 — словник команд терміналу (окремий вимикач)

- 619 токенів: busybox/coreutils, git, docker/compose, apt/pkg/dpkg, systemctl/journalctl,
  мережа (nmap, dig, tcpdump, ssh, scp, rsync, curl), python/node/npm/pip, типові шляхи
  (`/etc/`, `/var/log/`, `/sdcard/`…), `--help`/`--version`.
- Працює як **доповнення за початком**, а не виправлення: `doc` → `docker`, `/et` → `/etc/hosts`.
- Спрацьовує **лише на латиниці** — у кириличному слові підказки команд не зʼявляються.
- Вимикач: Налаштування → «Підказки команд (термінал)», типово вимкнено.

## v1.41.1-uk14 — виправлено зникнення клавіатури

- Причина: клавіатуру віддавали вікну (`setInputView`), коли вона ще була вкладена в контейнер зі
  смужкою підказок → `IllegalStateException: The specified child already has a parent`, вікно не
  показувалось, процес падав.
- Тепер усі шляхи йдуть через один метод `decorateInputView()`, який спершу відчіплює обидва вигляди.

## v1.41.1-uk13 — менше памʼяті + звіт про збій

- Словник більше не тримає 407 тисяч окремих рядків Java: один масив символів + таблиця зсувів,
  ~18 МБ замість ~27, без стрибка памʼяті при завантаженні.
- Налаштування → «Останній збій»: дата, потік, зайнята памʼять і стек останнього падіння.
  Саме цей звіт дав точну причину для uk14 замість здогадок.

## v1.41.1-uk12 — білі обʼємні клавіші з бузковими літерами

- Білі ковпачки: верхня площина з градієнтом, сіра бічна стінка, світле верхнє ребро, тінь у
  проміжку; при натисканні площина «просідає».
- Літери — бузковий `#7C4DFF`, додаткові символи — темніший бузковий `#5B2FA8`, щоб дрібні знаки
  відрізнялись від основних.

## v1.41.1-uk11 — обʼємні клавіша (перша версія)

- Малювання ковпачків кодом у `LatinKeyboardBaseView.onBufferDraw` — без nine-patch картинок.
- Вимикач «Обʼємні клавіші» в розділі графіки, застосовується без перезапуску клавіатури.

## v1.41.1-uk10 — справжні клацання

- Синтезовані звуки замінено на **реальні**, вирізані з запису користувача: три різні тембри,
  випадковий вибір на кожне натискання, щоб не звучало як метроном.

## v1.41.1-uk9 — механічне клацання

- Опційний звук натискання (`SoundPool`), вимикач у налаштуваннях звуку.

## v1.41.1-uk8 — смужка підказок, якої не було ніколи

- Справжня причина: системна `CandidateView` застаріла, і Android 11+ її просто не рендерить —
  тому підказок не було за жодних налаштувань.
- Смужку перенесено **всередину клавіатури**, над рядами клавіш; ховається, коли порожня.
- У ландшафті підказки увімкнені типово.

## v1.41.1-uk6 — ручне навчання замінам

- Довге натискання на підказці → діалог «Заміна одруківки»: що набрав / що мав на увазі.
- Власні заміни мають **вищий пріоритет** за словникові здогадки і переживають оновлення APK.
- Налаштування → «Мої заміни (одруківки)»: список, видалення, лічильник.

## v1.41.1-uk5 — словник 407 тисяч словоформ

- `wordfreq` (zipf ≥ 1.0) без hunspell-фільтра — він різав реальні відмінкові форми.
- Сортування за словом, зберігання одним масивом, двійковий пошук.

## v1.41.1-uk2 — коректор одруківок

- Зважена відстань Дамерау-Левенштейна: заміна сусідньої клавіші ×1, далекої ×5,
  транспозиція ×2, вставка ×3.
- Пороги `MIN_FREQ` і `MIN_AUTOCORRECT_SCORE`, щоб не «плющило» нормальні слова.

## v1.41.1-uk — перший український словник

- Офлайн-словник у `assets/uk_words.txt`, завантаження у фоновому потоці.
- Власний `Suggest`-шлях: `mUkDictionary` замість заглушки `main.dict` (34 байти).
- Корекція у звичайних текстових полях, але **не** в паролях, email, URL і фільтрах.
- Стабільний ключ підпису, збірка через GitHub Actions (локально SDK немає).

## Що варто знати

- APK ставиться поверх попереднього — підпис не змінюється.
- Після «Очистити дані» зникають збережені власні заміни (вони в SharedPreferences застосунку).
- Клавіатура не чіпає поля паролів, email і URL — це навмисно.
